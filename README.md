## 🚀 Quick Start (Local Setup)

### 1. Prerequisites
Make sure you have **Node.js** (version 18.0.0 or higher) installed:
```bash
node -v
```

### 2. Extract & Install
Unzip the downloaded `.zip` archive, open your terminal in the extracted folder, and run:
```bash
npm install
```

### 3. Launch the Local Dev Server
```bash
npm run dev
```
Your portfolio will be running locally at:
👉 **http://localhost:5173**

## 🛠️ How to Update Your Information

All of your portfolio data, theme choices, and section items are cleanly organized in a single file:
📂 **`src/data/portfolioData.ts`**

Open `src/data/portfolioData.ts` in your code editor to edit any of the following:

### 1. Personal Identity & Resume
- **Name & Title**: Update `personal.name`, `personal.firstName`, `personal.lastName`, and `personal.role`.
- **Hero Descriptions**: Customize `personal.heroSubTextLine1` and `personal.heroSubTextLine2`.
- **Resume (PDF)**: Paste your hosted PDF link in `personal.cvUrl`. When set, a styled **"Download Resume"** button automatically appears in your hero banner.
- **Profile Photo**: Update `personal.photoUrl` (use a remote URL or put an image inside `public/` and reference it like `'/avatar.png'`).
- **Photo Alignment**: Adjust `personal.photoPosition` (`'left'`, `'center'`, or `'right'`).

### 2. Theme & 3D Background
- **3D Animation**: Set `backgroundAnimation` to any of:
  `'dna'`, `'matrix'`, `'neural'`, `'particles'`, `'waves'`, `'cubes'`, `'quantum'`, `'constellation'`, `'blackhole'`.
- **Color Palettes**: Change `colorPalette` to `'neon-lime'`, `'cyber-blue'`, `'rose-gold'`, or `'aurora'`.
- **Custom Accent**: Use any custom hex color with `customAccentColor` (e.g. `'#c8ff00'`).

### 3. Skills & Expertise
- Edit the `expertise` array with your technical domains, descriptions, and 3D visualizer canvas types.

### 4. Featured Projects
- Update the `projects` array with your project titles, category tags, screenshots (`img`), case study descriptions, tech badges, and live demo / GitHub links.

### 5. Career & Timeline
- Update `timeline.training` with your degrees, certificates, or employment history.
- Update `timeline.hackathons` with hackathons, competitions, dates, and recognitions.

### 6. Custom Sections
- Customize or add items in `customSections` (Testimonials, Services, Awards, Publications, Interests & Hobbies, or custom tiles).

### 7. Contact & Socials
- Set `contact.email` so recruiters can email you directly.
- Add or modify URLs in `contact.socials` (GitHub, LinkedIn, Twitter/X, etc.).

## 🌐 Deploying to Vercel (Recommended)

Vercel provides the fastest deployment with global CDN and automated SSL certificates.

### Method A: Via GitHub (Continuous Deployment)
1. Initialize a git repository and push your project to [GitHub](https://github.com/new):
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Sign in to [Vercel](https://vercel.com) and click **"Add New..." > "Project"**.
3. Select and import your GitHub repository.
4. Vercel automatically detects the **Vite** preset:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"**. Your portfolio is now live! Every future `git push` will automatically rebuild and deploy your changes.

### Method B: Via Vercel CLI (Instant Terminal Deploy)
```bash
npm i -g vercel
vercel
```
Follow the command-line prompts to deploy directly without leaving your terminal.

## 🐙 Deploying to GitHub Pages

### Method A: Automated GitHub Actions Workflow (Zero config on git push)
1. Push your project to a GitHub repository.
2. Go to your repository on GitHub: **Settings > Pages**.
3. Under **Build and deployment > Source**, choose **GitHub Actions**.
4. Create a file in your project at `.github/workflows/deploy.yml` with this configuration:
```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: ['main']

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install Dependencies
        run: npm ci

      - name: Build Project
        run: npm run build

      - name: Setup Pages
        uses: actions/configure-pages@v4

      - name: Upload Build Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
5. Commit and push to `main`. GitHub Actions will build and deploy your site automatically to:
   `https://<your-username>.github.io/<your-repo-name>/`

### Method B: Using `gh-pages`
```bash
# 1. Install gh-pages package
npm install -D gh-pages

# 2. Add deploy script to package.json:
# "deploy": "npm run build && gh-pages -d dist"

# 3. Build & publish
npm run deploy
```
